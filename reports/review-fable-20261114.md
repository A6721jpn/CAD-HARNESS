## 3. 復旧方針の優先順位

1. **証拠採取（手順0と1）。** 変更なしで30分程度です。これを飛ばして再起動や修復をすると、直っても直らなくても理由が残りません。
2. **hub 再起動。** 安く、溜まった状態を一掃できます（障害後も残った ViewServer、9個分のランチャー、SWVisualize のサービス）。
   - 【推測】単独で直る見込みは高くありません。10/28 は環境を入れ替えて起動した直後にも落ちています。
   - 再起動後のログイン方法（コンソールの自動ログオンか、リモート経由か）でセッションの GPU 利用が変わりうるので、手順0のセッション確認とセットにします。
   - 他エージェントに影響するため、ユーザー判断です。
3. **手動確認と M0（手順2と3）。**
4. **Software OpenGL 比較（手順4）。**
5. **表示構成の是正。** モニターなしの GPU は既定の 1024x768 出力を持ち、仮想ディスプレイは別アダプタ扱いです。
   - 【推測】OpenGL アプリは窓が載る画面のアダプタでドライバが選ばれるため、SW が GPU の OpenGL を掴めていない、または表示構成の変化（リモート接続の接続と切断、解像度変更）でコンテキストを失う可能性があります。
   - 対策候補は、HDMI ダミープラグで RTX に実画面を持たせる（GPU アプリの無人運用では最も堅実）、仮想ディスプレイを唯一かつ主画面にして描画 GPU を RTX に固定する、run 中はリモート接続の着脱と解像度変更をしない、の3つです。
6. **GPU ドライバ。** 10/22〜26 の安定期の版を特定し、クリーンインストールで揃えます。10/27 に TDR が出ているので、ドライバと GPU の安定性は独立に疑う価値があります。
7. **SolidWorks の修復または HF の確認。** 最後です。同じインストールで 53084 が31時間動いた事実があり、インストール破損の見込みは低いと見ます。
8. **Dassault サポートへの照会。** ダンプが採れたら並行で出します。

**環境ゲートと耐障害性**
- 復旧の合格条件を事前に書き、「1回成功」を条件にしない。BLOCK 解除条件と、解除できない場合の期限と代替も決めておく。
- 課金呼び出しの直前に数秒の無課金カナリア（文書数確認と最小部品の作成と破棄）を入れる。SW が死んでいたら課金前に止まります。
- モデル出力（ビルド仕様 JSON）の保存と CAD 実行を分離する。SW 障害で CAD に進めなかった課金済み出力を、復旧後に再課金なしで実行できるようにします。時間枠の扱いに関わるので、次の事前登録で規則として明記します。
- SW の PID は凍結対象の同一性から外し、運用パラメータとして記録する。SW が落ちるたびに新バンク、20制御、新凍結をやり直す構造が最大の脆さです。
- クラッシュ採取（LocalDumps、終了監視、SW ジャーナルの退避）を常設にする。
- ホスト指紋を毎 run 記録する。起動時刻、GPU ドライバ版、仮想ディスプレイ版、SW 版と HF、表示構成、セッション種別です。epoch 中は Windows、ドライバ、SW の自動更新を止めます。

**比較手順（合格ライン、policy、カード、採点は変えない範囲。事前登録とユーザー判断が必要）**
- モデルのタイムアウトで usage が取れない試行を「比較不能」として捨てない。失敗として比較に残す規則にします。
- 無益性の早期停止を入れる。残りを全勝しても採用条件に届かない時点で打ち切ります。
- 1題を5回ではなく、複数題に広げる。採用条件の検出力を事前に計算しておきます。
- 「形状が正しいか」と「時間内に終わったか」を別指標として併記する。公式の合否は変えず、時間切れ分を時間無制限で再検証した参考値を付けるだけです。
- ホールドアウトの「5題全合格」と「平均時間が少しでも悪化したら不採用」は、難度30〜70%の課題では事実上通らないので、見直しを検討してください。

**記録**
- 5〜10行の現況ファイルを1つ作る（状態、残予算、次の一手、禁止事項）。`H0_PROGRESS.md` は追記ログに徹します。
- SW 復旧の runbook を置く。`tools/README.md` の「retired」記述を直し、11/04 の操作を記録します。
- 未追跡の BLOCK 根拠を commit するか退避するか決める。
- 3DEXPERIENCE のライセンス条件（無人、長時間、自動操作）の確認を、未確認のまま進めない。
