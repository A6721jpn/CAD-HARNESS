## Pass criteria — user values only

- U1: NF-13CR inner 245 × 365 × 140 mm; part Y (longest outer axis) vertical; play <=0.5 mm; tape 0.5 mm; count not specified; numbers engraved. No other number is a pass limit.
- U2: 10 pieces; glass 1.3 mm; no contact on the 1.3 mm perimeter band; convex face may contact; concave contact minimal; no rattle. No maximum outer size (C-A). U1's 0.5 mm play is not a U2 limit.
- U3: <=0.005 mm absolute deviation. Continuity is G2 under C-A, not the request's G3, once that supersession is written. No curvature-residual number was given.
- U4: thickness 2 mm; surrounding outer dimensions unchanged. No tolerance was given. "いい感じ" is not a critical dimension.
- U5: thickness and logo size are parameters; minimum tool R is 0.25 mm. The logo file is the supplied raster, not a web fetch. Plate outline, default thickness, and default logo size may be agent defaults only if labelled and frozen in C-U5 before trial. They are not user dimensions.
