# LLMに3D CADを使わせるための評価ハーネス

## 何を確かめるのか

LLM（文章を扱う生成AI）が、人の依頼を読み取り、意図した立体を正しく作れるかを確かめるための仕組みです。
3D CADは、立体の形や寸法を設計する道具です。
ここでいう「ハーネス」は、AIへの依頼、形の作成、採点を同じ条件で繰り返すための検証の仕組みを指します。

確かめたいのは、AIがもっともらしい説明を返せるかではなく、依頼に合う形を実際に作れるかです。
さらに、AIに渡す説明を改善すると、正しく作れる割合が本当に上がるのかを調べます。

## なぜ役割を分けるのか

### AIは設計をデータで返す

AIは、形、寸法、穴や切り欠きなどを、項目ごとに整理した設計データ（JSON）として返します。
これにより、AIが依頼をどう解釈したかを、実際の作図とは分けて扱えます。

### 決まったコードがCADを操作する

設計データを受け取った固定のプログラムが、COM（外部のプログラムからソフトを操作する仕組み）を通じてSolidWorksを操作します。
AIが毎回、操作プログラムそのものを書き換える方式にはしません。

操作方法を揃えることで、設計の理解が良くなったのか、たまたま別の操作方法がうまくいったのかを混同しにくくします。

### 作成に使ったCADとは別のツールで採点する

完成した形は、異なるCAD間で立体を受け渡すための形式であるSTEPに書き出します。
それをFreeCADに読み込み、正解として用意した形と独立に照合します。

SolidWorksが「操作に成功した」と返したことや、見た目が似ていることだけでは合格にしません。
寸法、穴や切り欠き、立体としての正しさ、形全体のずれを調べます。
一部の点や体積の一致だけで判断せず、あらかじめ決めた許容範囲に収まるかを厳密に確認します。

## 公平に改善を比べるために

評価に使う課題、合格ライン、CADの操作コード、採点方法を先に決め、比較中は変えません。
正解の設計データもAIには見せません。

変更するのは、AIに渡す作図の手引きである「スキル文」だけです。
同じ課題を、元の手引きと改善候補の手引きで交互に解かせ、複数回の結果を比べます。
交互に試すことで、試した順番やその時々の条件の違いに結果が偏りにくくします。

合否に加え、依頼にない形を勝手に足していないか、やり直しや所要時間が増えていないかも確認します。
成績の良い回だけを選ばず、失敗も含めて評価します。
改善に使っていない別の課題でも確かめ、一度成功しただけで良くなったとは判断しません。
